# Plastic Tears Resources

Photoshop scripts, actions and links we use for scanlation (cleaning, typesetting, SFX). Grab whatever's useful.

Some scripts are ours, some are other people's (credit is inside each file), and some are other people's that we tweaked.

## What's here

| Folder ||
|---|---|
| `Scripts/` | Photoshop scripts (`.jsx`) |
| `Actions/` | Photoshop actions (`.atn`) |
| `Guides/` | Reference images |
| `Links/` | Guides, dictionaries, SFX lists, font sites and Discord servers |

## Installing scripts

Put the `.jsx` files in `Photoshop/Presets/Scripts/` and restart Photoshop. They'll show up under **File > Scripts**. Or run one directly with **File > Scripts > Browse...**

Actions: **Actions panel > menu > Load Actions...** and pick the `.atn`.

## Related

- **[Auto Insert Txt to Comic](https://github.com/luigidesu/Auto-Insert-Txt-to-Comic)** (separate repo): typesets a whole chapter from the translation file.
- **[Bubble Cleaner](https://github.com/luigidesu/Bubble-Cleaner)** (separate repo): erases the text in speech bubbles. Select them, run it, done.
